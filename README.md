# 👽 Ejercicio Java: Máquina de Aliens

### Descripción
Ejercicio de programación en Java que representa una máquina de aliens. El código fuente del proyecto se encuentra en `src/`.

### ⚙ Requisitos
- Java Development Kit (JDK) compatible con el código del proyecto.
- Un IDE de Java o herramientas de compilación de Java.

### 🚀 Uso
Clona el repositorio y abre el proyecto en tu IDE:
```bash
git clone https://github.com/Felipezc97/ejercicio-java-maquina-aliens.git
cd ejercicio-java-maquina-aliens
```
Revisa el código bajo `src/` para identificar la clase principal y ejecutar el ejercicio.
